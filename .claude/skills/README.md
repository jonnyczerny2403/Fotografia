# Skills do Taste Skill

As skills oficiais completas serão instaladas automaticamente aqui pelo `scripts/bootstrap.sh` na primeira sessão (ou quando ausentes/corrompidas):

- `design-taste-frontend/` — `https://github.com/Leonxlnx/taste-skill`, pasta `skills/taste-skill`.
- `high-end-visual-design/` — `https://github.com/Leonxlnx/taste-skill-classics`, pasta `skills/soft-skill`.

Não crie `SKILL.md` falsos ou resumidos nesta pasta: o gate exige os arquivos oficiais e seus scripts/referências. A instalação exige acesso a github.com e Git; Stripe/Netlify exigem autorização separada.
